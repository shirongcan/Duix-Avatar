# Local background replacement

This helper uses the MobileNetV3 TorchScript weights from
[Robust Video Matting](https://github.com/PeterL1n/RobustVideoMatting) (RVM).
RVM is licensed under GPL-3.0 and was developed for temporally coherent human video matting.

The model file used by HeyGem is:

`models/rvm_mobilenetv3_fp16.torchscript`

Official release URL:

`https://github.com/PeterL1n/RobustVideoMatting/releases/download/v1.0.0/rvm_mobilenetv3_fp16.torchscript`
